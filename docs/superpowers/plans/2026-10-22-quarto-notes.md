# Доопрацювання конспектів через Quarto — Implementation Plan

**Статус виконання:** реалізовано в `feature/quarto-notes` поверх `notes-generation-engine@2829b7b`; P3.3 перевірено контрольним курсом. Подробиці перевірок і чинні контракти наведено в [README](../../../README.md), [E2E](../../../web/e2e/notes/README.md) та [рішеннях](../specs/2026-10-23-quarto-notes-decisions.md). Нижні чеклісти підпланів збережено як початкові завдання, а не як поточний ledger.

**Goal:** Реалізувати всі напрями покращення конспектів: структуру, оформлення, математику, джерела, HTML/PDF/Word, редагування, AI-доопрацювання та книгу курсу.

**Architecture:** `NotesDocument` залишається основним джерелом змісту. Quarto будує вихідні файли з незмінної ревізії; worker керує записом і рендерингом. Три підплани дають окремі перевірювані результати.

**Tech Stack:** Python >=3.12, FastAPI/Pydantic, Next.js/React/TypeScript, Quarto, Typst, MathJax; наявне файлове сховище.

**Spec:** [Специфікація](../specs/2026-10-22-quarto-notes.md).

## Global Constraints

Усі вимоги розділу «Глобальні вимоги» специфікації застосовуються до кожної задачі. Код планується поверх `notes-generation-engine@2829b7b`; перехід на `engine-reset` потребує переприв'язки плану.

## Review Focus

| Умова | Очікувана поведінка | Де перевіряється |
|---|---|---|
| Старий run без нових полів | Доступний для читання й міграції без втрати тексту | P1.1, P2.1 |
| Дві вкладки з тією самою базовою ревізією | Одне збереження, друге отримує 409 і зберігає локальну чернетку | P2.1, P2.2 |
| Помилка Quarto або перезапуск worker | Текст збережений, попередній артефакт доступний із номером ревізії | P1.2, P2.3 |
| Зміна теми з доказами або посиланнями | Перевірка стає неактуальною; інші IDs і джерела зберігаються | P1.4, P2.1, P2.4 |
| Українська, довгі формули й таблиці в різних форматах | Читабельні HTML/PDF/Word; без обрізання змісту | P1.3, P3.1, P3.3 |

## Перед початком

- [ ] Перевірити актуальні `git status`, гілку й інструкції репозиторію; для web прочитати `web/AGENTS.md` та відповідні локальні Next.js docs.
- [ ] Зафіксувати базою `notes-generation-engine`; якщо команда вже перейшла на `engine-reset`, спочатку оновити всі три підплани під її контракти.
- [ ] Запустити базові `make test`, `make lint`, `cd web && npm run build`; відділити наявні помилки від регресій.
- [ ] Підготувати синтетичний двомовний курс із двома темами; не додавати реальні приватні підручники у fixtures.

## Етапи поставки

- **Етап 1:** читабельні HTML/PDF, узгоджена структура, джерела й переходи. Показати одну тему та повний конспект.
- **Етап 2:** викладач редагує, порівнює й відновлює версії, застосовує AI-пропозиції; ручне редагування працює без LLM.
- **Етап 3:** Word, книга курсу з пошуком і перевірка всього сценарію. Усі рекомендовані напрями закриті.

## Межі та подальші дії

Історичні кроки «Перед початком» і команди в підпланах описують спосіб реалізації, а не незавершені дії. Поточний стан визначає таблиця вище; зовнішній деплой і перевірка в Microsoft Word не входили до цього приймання.
