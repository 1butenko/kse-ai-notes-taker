# Dev docs workflow runs the Claude Code CLI directly

- **Date:** 2026-11-15
- **Branch:** feature/autonomous-course-create
- **Commits:** 0b1b74e..84bc5d6

## What changed
- The Dev docs workflow no longer uses `anthropics/claude-code-action@v1`. It installs Node 22 and `@anthropic-ai/claude-code`, then runs `claude -p` with the same prompt.
- The `id-token: write` permission was removed.
- The prompt values (mode, range, branch, head commit, date) are passed through env vars and shell expansion.
- If `ANTHROPIC_API_KEY` is empty it is unset, so `CLAUDE_CODE_OAUTH_TOKEN` is used.
- The `Bash(date:*)` tool permission was dropped; the date is computed in the shell.

## Why
claude-code-action v1 rejects push events ("Unsupported event type: push").

## Where
- [dev-docs.yml](../../../.github/workflows/dev-docs.yml): the "Write the docs with Claude" step.

## API and data
None.

## How to try it / migrate
Nothing to do. Push to `main` or `feature/**` to run the workflow.
