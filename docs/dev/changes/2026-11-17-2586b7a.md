# Skip Claude review on Dependabot PRs; match @types/node to Node 24

- **Date:** 2026-11-17
- **Branch:** main
- **Commits:** 8a3cc55184eef5f663dad29e3aa245902a8d52d5..2586b7aa47fb43b982abf8feeec3b32df5fc0ad1

## What changed
- The `claude-review` job no longer runs on PRs opened by `dependabot[bot]`.
- Dependabot ignores major updates of `@types/node` in `/web`.
- `@types/node` in `web/package.json` moves from `^20` to `^24.19.2`, matching the `node:24` runtime.

## Why
Dependabot PRs run without repository secrets, so `claude-review` always failed. `@types/node` should follow the `node:24` runtime in `web/Dockerfile`, not the latest Node major.

## Where
- [claude-code-review.yml](../../../.github/workflows/claude-code-review.yml): `if` condition on the `claude-review` job.
- [dependabot.yml](../../../.github/dependabot.yml): `ignore` rule for `@types/node` major updates (npm entry).
- [package.json](../../../web/package.json) and `web/package-lock.json`: `@types/node` bump.

## API and data
None.

## How to try it / migrate
Run `npm install` in `web/`, and rebuild the web container if needed: `docker compose up -d --build -V web`.
