# Langfuse: cost, per-user and per-session tracking

- **Date:** 2026-11-18
- **PR:** #54
- **Branch:** feat/langfuse-cost-user-session → main

## What changed
- Every model call is traced in Langfuse with the signed-in teacher as `user_id` and the course (`course-<key>`) as `session_id`.
- Each generation records the served model, token usage and OpenRouter's reported cost.
- Traces: `transcribe-syllabus`, `map-materials`, `transcribe-pages`, `prepare-course` (orchestrator + Moodle subagent) and `lecture-notes`.
- Attached PDFs are stripped from traced input; the model still gets them. Text prompts are still traced.
- The API stamps `user_id` on worker requests (`worker_contract.Traced`, set in `get_worker_client`). Direct OpenRouter calls request `usage: {include: true}`.
- Langfuse environment comes from `ENVIRONMENT`; `compose.prod.yaml` sets `production`. Adds the Langfuse agent skill.

## Why
Closes #18: see who made each call, per course, and what it cost.

## Where
- [tracing.py](../../../api/app/tracing.py): `traced`, `generation`, usage and cost mapping, `without_files`, LangChain callback handler.
- [worker_contract.py](../../../api/app/worker_contract.py), [worker_client.py](../../../api/app/worker_client.py): `Traced`, `user_id` filled from the principal.
- [main.py](../../../api/app/worker/main.py), [llm.py](../../../api/app/worker/llm.py), [openrouter.py](../../../api/app/worker/openrouter.py): traces per endpoint, generations in `ask()`, usage with cost.
- [sync.py](../../../api/app/note_taker/sync.py): `prepare-course` trace.
- [lecture_notes/tracing.py](../../../api/app/note_taker/lecture_notes/tracing.py), [runs.py](../../../api/app/note_taker/lecture_notes/runs.py): use the shared helpers.
- [prompts.py](../../../api/app/prompts.py), [config.py](../../../api/app/config.py): Langfuse client environment, setting comments.
- [test_tracing.py](../../../api/tests/test_tracing.py): user, session, usage, cost and PDF stripping.

## API and data
No new endpoints or tables. Worker request bodies gain an optional `user_id`. `ENVIRONMENT=production` is set for `api` and `worker` in `compose.prod.yaml`.

## How to try it / migrate
Nothing to do. Set the `LANGFUSE_*` keys to see traces; `LANGFUSE_TRACING=false` turns them off.
