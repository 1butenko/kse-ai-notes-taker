# Multiple users: course members, admins, activity log

- **Date:** 2026-11-19
- **PR:** #62
- **Branch:** feature/multi-user → main

## What changed
- A course belongs to a team: one lecturer (whoever sets it up; can hand the role over and stays on as a TA) and any number of TAs added by email, even before their first sign-in.
- TAs do everything on a course except manage members and start it over (403). People with no role get 404.
- Admins (`PLATFORM_ADMINS`) have a lecturer's rights on every course and see all courses. `OPEN_COURSE_ACCESS=true` makes everyone an admin (test servers). `SHARED_COURSES` is removed.
- Setting up a course that already has a lecturer gives a 409 naming them.
- An activity log (`course_events`) records uploads, syllabus deletes, Moodle syncs, notes runs, readings approval and revoke, member changes, hand-over and start over.
- The web adds Course and Team tabs, role badges, member management, hand-over and the activity list (merged from #63).

## Why
Courses were owned by one teacher, plus an env list of shared sandbox courses. Teams need to work together (#44) and test servers need open access (#45).

## API and data
- New: `GET /team/{course}`, `POST /team/{course}/members`, `DELETE /team/{course}/members?email=`, `PUT /team/{course}/lecturer`, `GET /team/{course}/activity?limit=`.
- `GET /course-info` items carry `role`; `DELETE /course-info/{course}` needs the lecturer or an admin.
- Tables `course_members` and `course_events`; `owner_id` is still written. Existing owners become lecturers and earlier runs are logged once.
- Env: `PLATFORM_ADMINS`, `OPEN_COURSE_ACCESS`, `MEMBER_EMAIL_DOMAINS` (default `kse.org.ua`). `SHARED_COURSES` is ignored.
- `manage.py claim-course` is now `set-lecturer`.

## How to try it / migrate
Run `make db-init` against production before deploying: without the new tables every course request fails. If production's `SHARED_COURSES` listed a sandbox course, make its users members or admins afterwards. Set `PLATFORM_ADMINS` in `/kse-notes/env`. Database tests: `TEST_DATABASE_URL=... uv run pytest -m database`.
