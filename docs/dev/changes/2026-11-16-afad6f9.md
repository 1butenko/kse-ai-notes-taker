## What changed
- Merged `main` into `feature/autonomous-course-create`. The only non-docs change is two new GitHub workflows.
- `claude.yml` runs Claude Code when `@claude` appears in an issue, issue comment, PR review or PR review comment.
- `claude-code-review.yml` runs an automatic code review on every PR (opened, synchronize, ready_for_review, reopened) and posts inline comments.
- Both use `anthropics/claude-code-action@v1` with the `CLAUDE_CODE_OAUTH_TOKEN` secret.
- `docs/dev/` gained the earlier 2026-11-15 change entry from `main`.

Commits "Add Claude Code GitHub Workflow", "Claude PR Assistant workflow" and "Claude Code Review workflow". Beyond that: not stated.

## Where
- [claude.yml](../../../.github/workflows/claude.yml): `@claude` assistant. Read-only permissions plus `id-token: write` and `actions: read`.
- [claude-code-review.yml](../../../.github/workflows/claude-code-review.yml): PR review using the `code-review@claude-code-plugins` plugin.

## API and data
None. Needs the repo secret `CLAUDE_CODE_OAUTH_TOKEN`.

## How to try it / migrate
