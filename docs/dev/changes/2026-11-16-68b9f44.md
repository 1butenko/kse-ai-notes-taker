# Sign-in with Google, course ownership, AWS deployment

## What changed
- Teachers sign in with their KSE Google account (Auth.js in the web). Only accounts whose verified ID token has an `hd` claim in `AUTH_ALLOWED_DOMAINS` (default `kse.org.ua`) get in.
- The browser no longer calls the API directly. The web's route handler `/api/[...path]` forwards every call to FastAPI with a 60-second HS256 token signed with `API_AUTH_SECRET`. The old `next.config.ts` rewrite is gone.
- Every API route now needs a token. `sub` is a `users.id` (a teacher) or `worker` / `web` (services). Course routes check that the course belongs to the teacher; other teachers' courses answer 404. Services may touch any course.
- Courses have an owner (`courses.owner_id`). `PUT /course-info/{course}` creates a course for the caller (409 if another teacher has it); `DELETE` releases it. `GET /course-info` lists only the caller's courses.
- New `/me` (get, update names) and `/auth/sync` (web only) endpoints; new `users` table; account page in the web.
- Dashboard split into a course list and a per-course view; KSE logos and an SVG app icon.
- Backend deploys on AWS EC2 behind CloudFront with `compose.prod.yaml` and `scripts/aws/deploy.sh`. `render.yaml` is removed.

## Why
From the commits: teachers sign in with KSE Google accounts, the web forwards calls as the signed-in teacher, the worker signs its own calls, and courses get an owner. The backend moved from Render to AWS. Other reasons: Not stated.

## API and data
- New env vars: `API_AUTH_SECRET` (same for web, api, worker), `AUTH_SECRET`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`, `AUTH_ALLOWED_DOMAINS`. `compose.yaml` also sets `AUTH_URL` and `AUTH_TRUST_HOST` for the web.
- New table `users`; new column `courses.owner_id`.
- New endpoints: `POST /auth/sync`, `GET /me`, `PATCH /me`. All other routes return 401 without a valid bearer token, except the published lecture-notes site `GET /lecture-notes/runs/{run_id}/site/{path}`, which is public.
- Without `API_AUTH_SECRET` the API answers 503.

## How to try it / migrate
- Fill the new variables in `.env` (see `.env.example`); redirect URI `http://localhost:3000/api/auth/callback/google`.
- Run `uv run python -m app.manage init-db` to add `users` and `owner_id`.
- Existing courses have no owner. After the teacher has signed in once: `uv run python -m app.manage claim-course <course_key> <email>`.
- Rebuild the web container (new packages): `docker compose up -d --build -V web`.
