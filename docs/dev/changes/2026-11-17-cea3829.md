## What changed
- Adds `.github/dependabot.yml` with version updates for `uv` (`/api`), `npm` (`/web`), `docker` (`/api`, `/web`) and `github-actions` (`/`).
- `uv` and `npm` run weekly on Monday, with minor and patch updates grouped into one PR each, and at most 5 open PRs.
- `docker` and `github-actions` run monthly; Actions updates are grouped into one PR.
- Commit prefixes are `deps(api)`, `deps(web)`, `deps(docker)` and `deps(actions)`.
