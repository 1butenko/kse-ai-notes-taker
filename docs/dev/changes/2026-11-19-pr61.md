# Web: override katex and minimatch to patched versions

- **Date:** 2026-11-19
- **PR:** #61
- **Branch:** fix/web-security-overrides → main

## What changed
- `rehype-katex` and `micromark-extension-math` now use the root `katex` (0.19.1) instead of their own pinned `katex@^0.16`. This fixes a low-severity prototype pollution (fixed in 0.18.2).
- `@ts-morph/common` (pulled in by `shadcn` → `ts-morph`) now uses `minimatch` `^11.0.9` instead of 10.2.6. This fixes a medium-severity ReDoS (fixed in 11.0.1). It only affects the shadcn CLI (dev).
- Two npm `overrides` added to `web/package.json`; `web/package-lock.json` regenerated. No application code changed.

## Why
Closes the two open Dependabot alerts in `web/package-lock.json` (katex and minimatch).

## Where
- [package.json](../../../web/package.json): new `overrides` block (`"katex": "$katex"`, `@ts-morph/common` → `minimatch ^11.0.9`).
- [package-lock.json](../../../web/package-lock.json): resolved versions updated; nested katex and minimatch 10 entries removed.

## API and data
None.

## How to try it / migrate
Run `npm ci` in `web/`. The Docker web container needs a rebuild: `docker compose up -d --build -V web`.

## Docs updated
- `docs/dev/README.md`: Recent changes line for this PR.

## Follow-ups
- The `overrides` can be dropped once `rehype-katex`, `micromark-extension-math` and `@ts-morph/common` ship patched ranges themselves (probably).
