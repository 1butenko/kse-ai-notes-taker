# Show the note taker's progress as a trace of steps and actions

- **Date:** 2026-11-24
- **PR:** #70
- **Branch:** feat/trace-progress → main

## What changed
- Each progress action records the todo in progress when it started (`todo`). Up to 100 actions are kept (was 40).
- The course agent console and the lecture notes progress section show a trace: steps with their actions grouped under them.
- The trace is one shared `AgentTrace` component, built on new shadcn `trace` and `collapsible` components.
- The console's own progress list and the `indeterminate` animation in `globals.css` are removed.

## Why
Not stated beyond the commit: so the pages group actions under their steps in one shared component.

## Where
- [progress.py](../../../api/app/note_taker/progress.py): `Action.todo`, `Progress.active_todo()`, `MAX_ACTIONS = 100`; `flush` saves `todo`.
- [agent.py](../../../api/app/routers/agent.py): `AgentAction.todo` (optional).
- [agent-trace.tsx](../../../web/src/components/agent/agent-trace.tsx): the shared trace.
- [trace.tsx](../../../web/src/components/ui/trace.tsx), [collapsible.tsx](../../../web/src/components/ui/collapsible.tsx): new UI components.
- [agent-console.tsx](../../../web/src/components/course/agent-console.tsx), [visual-notes-section.tsx](../../../web/src/components/lecture-notes/visual-notes-section.tsx): use `AgentTrace`.
- [api.ts](../../../web/src/lib/api.ts): `AgentAction.todo`.

## API and data
`AgentAction` gains optional `todo` (string or null). It is stored in the existing `actions` JSON of `sync_runs` and `lecture_note_runs`; no schema change.

## How to try it / migrate
Nothing to do. Older runs have no `todo` on their actions.
